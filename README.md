# Sistema de Registro de Colaboradores                                                                                                                        
                                                                                                                                                                 
   aplicacion de escritorio en Java con JavaFX para el registro y gestión de colaboradores.                                                                      
                                                                                                                                                                 
   ## tecnologias                                                                                                                                                
   - Java 25                                                                                                                                                     
   - JavaFX 21                                                                                                                                                   
   - Maven                                                                                                                                                       
   - Lombok                                                                                                                                                                                                                                                                                                          
                                                                                                                                                                 
                                                                                                                                  
                                                                                                                                                                 
   ## Estructura                                                                                                                                                 
   - `DistributorApplication.java` — punto de entrada de la app                                                                                                  
   - `controllers/` — controladores de las vistas                                                                                                               ▄
   - `models/` — modelos de datos (Collaborator)                                                                                                                █
   - `utils/` — utilidades                                                                                                                                      █
   - `resources/` — vistas FXML y recursos gráficos
